# 📊 数据分析实战项目

两个完整的数据分析项目，涵盖数据清洗、探索性分析、机器学习建模与业务洞察。

## 项目列表

### 🚲 [共享单车需求预测](01-bike-sharing-demand/)
- **数据**：Washington D.C.，10,886条小时级骑行记录
- **方法**：时间序列分析 + 随机森林/XGBoost
- **成果**：R²达0.85+，输出运营调度建议

### 🛒 [电商RFM客户分群](02-ecommerce-rfm/)
- **数据**：英国电商UCI数据集，54万+条交易记录
- **方法**：RFM模型 + K-Means聚类
- **成果**：轮廓系数0.62，输出差异化营销策略

## 技术栈
Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | XGBoost
